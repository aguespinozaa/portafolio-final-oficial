# 🌟 Portafolio · Agustina Espinoza

¡Bienvenida o bienvenido a mi portafolio digital! Este repositorio contiene el código fuente de mi página web personal desarrollada en el marco del **Taller de Diseño de Interfaces**. Aquí recopilo y exhibo una serie de proyectos interactivos centrados en la programación creativa, la experimentación con hardware, la interacción mediante voz, el procesamiento de audio y el desarrollo de videojuegos web.

---

## 🚀 Proyectos Desticulados

El portafolio actual incluye 6 proyectos principales que exploran distintas áreas de las interfaces interactivas:

1. **Juego Musical**
   * *Descripción:* Experiencia interactiva desarrollada para explorar distintos géneros musicales mediante el juego y la escucha activa.
   * [Ver proyecto en vivo](https://aguespinozaa.github.io/juego-musical/)

2. **Transcriptor de Voz**
   * *Descripción:* Aplicación web interactiva que utiliza la API de reconocimiento de voz del navegador para transformar audio en texto en tiempo real.
   * [Ver proyecto en vivo](https://aguespinozaa.github.io/transcriptor-voz/)

3. **Proyecto Interfaz**
   * *Descripción:* Demostración audiovisual de una interfaz interactiva enfocada en la experimentación y el procesamiento de audio.
   * [Ver registro en video](https://youtu.be/yAoMCGDHWFM?si=5AtaiwbOWanipdzB)

4. **Sonido e Imagen**
   * *Descripción:* Proyecto interactivo que conecta características visuales de una imagen con diferentes respuestas y estímulos sonoros.
   * [Ver proyecto en vivo](https://aguespinozaa.github.io/sonido-imagen/)

5. **Lámpara Rapunzel**
   * *Descripción:* Lámpara interactiva de hardware y software diseñada para encenderse e iluminarse mágicamente al detectar una frase específica mediante comandos de voz.
   * [Ver proyecto en vivo](https://aguespinozaa.github.io/lampara-rapunzel/)

6. **Supernova Game**
   * *Descripción:* Juego arcade espacial desarrollado con **p5.js** donde controlas un cohete para esquivar meteoritos y destruir estrellas en el espacio.
   * [Ver proyecto en vivo](https://aguespinozaa.github.io/juego-supernova/)

---

## 🛠️ Tecnologías y Herramientas Utilizadas

* **HTML5 y CSS3:** Estructuración semántica de la página, diseño responsivo mediante CSS Grid y Flexbox, efectos visuales con `backdrop-filter` y degradados dinámicos.
* **JavaScript (ES6):** Interactividad general del sitio y lógica de control.
* **p5.js:** Librería utilizada para el desarrollo del videojuego y elementos gráficos interactivos.
* **Web Speech API:** Utilizada en los proyectos de comandos de voz y transcripción.
* **GitHub Pages:** Plataforma de despliegue y alojamiento web.
